# Shoot Planner 📸
A professional desktop application designed for photographers to manage schedules and gear.

### 🚀 How to Download
1. Go to the **Releases** section on the right side of this page.
2. Download the `ShootPlanner_v1.zip` file.
3. Extract the file using WinRAR and run `shoot_planner.exe`.

### ✨ Key Features
* **Dual Access:** Admin and User modes for team coordination.
* **Database:** Persistent storage using SQLite.
* **Aesthetic UI:** Modern dark-mode design.
